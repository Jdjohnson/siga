# Credits and reuse

Sigá’s source and project artwork are distributed under the repository’s MIT license, except for third-party font software, which has its own license.

## Lettering

The outlined wordmark is derived from [Fraunces](https://github.com/google/fonts/tree/main/ofl/fraunces), designed by Undercase Type. Fraunces is available under the SIL Open Font License 1.1. The [license notice](licenses/Fraunces-OFL.txt) is included. No font binary is needed to display the supplied outlined SVG assets.

## Wave mark

The original Sigá wave drawing is retained in `../assets/siga.svg`. The menu-bar mark retains all three waves. The wordmark accent and release app icon use a thicker version of the top wave.

## Photograph

The website photograph was generated using the OpenAI image-generation tool. It depicts a fictional person dictating to a Mac while wearing headphones. It is illustrative brand artwork, not a customer testimonial or an endorsement by a hardware manufacturer. The exact generation brief is kept privately as prompts.md. It is not part of this repository or the public source archive.

The earlier Calendly reference boards guided the exploration; they are not included in the release and no Calendly logo, typography asset, or screenshot is shipped.

## App icon finish

Build 13 uses an OpenAI-generated refinement of the original single-wave icon, with a restrained brand-blue gradient and fine paper texture. The production raster is `assets/app-icon-1024.png`; `../assets/app-icon.svg` preserves the original flat vector construction.
