# Sigá website

The static site is live at [getsiga.app](https://getsiga.app). It uses plain HTML and CSS, with a small script for the FAQ. The answers still open without JavaScript.

Both app buttons lead to the signed and notarized Sigá 0.2 build 18 release. The source link downloads the build 18 source archive. When updating the site, check the live app download against the notarized DMG and keep the source archive tied to the reviewed app code.
