# Sigá website

The static site is live at [getsiga.app](https://getsiga.app). It uses plain HTML and CSS, with a small script for the FAQ. The answers still open without JavaScript.

Both app buttons lead to the signed and notarized Sigá 0.2 build 18 release candidate. The source link downloads an archive of the current public repository. When updating the site, check the live app download against the notarized DMG and regenerate the source archive from the reviewed commit.
